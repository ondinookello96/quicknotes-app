# QuickNotes App

QuickNotes is a clean, responsive, and feature-rich note-taking web application built with vanilla HTML, CSS, and JavaScript. It allows users to capture, categorize, search, and manage their daily thoughts with client-side data persistence.

## Features

- **Categorized Notes:** Organize notes under Personal, Work, or Study categories, each styled with unique left-border accents.
- **Form Validation:** Prevents empty submissions and enforces a 200-character limit with instant error messaging.
- **Dynamic Counters:** Real-time note counts that adapt to singular, plural, and zero states.
- **Live Search:** Instant case-insensitive filtering of notes as you type.
- **Data Persistence:** Notes are automatically saved to and loaded from `localStorage` using JSON serialization.
- **Responsive Layout:** Flexbox-based form and card layouts that gracefully adapt to mobile screens via media queries.
